| Purpose | Project to wrap security, quality and reliability tools and run them against an existing repository, service or cloud. |
| Intended users | SaaS developers. |
| User problem | Wraps many valuable security, reliability and quality tools, much of it open source and executes them systematically against a code base with baselining and reporting. |
| Expected value | Identify many low/medium level security, reliability and quality issues before engaging professional pen testing, compliance or auditing companies. |
| Initial scope | Fetch and execute specified tools. |
| Success criteria | Identifies low/medium level, common security, reliability and quality issues for coding agent outputs. |
| Constraints and exclusions | Only identifies issues identifiable through the tools this wrapper uses. A pass does not imply the codebase, deployment or cloud configuration being tested is totally secure against attackers. Does not perform DDoS testing, instead finding issues that would make such attacks cheap. |
